## 📌 Overview

A comprehensive open-source guide for both beginner and experienced QA professionals.

This repository covers:

- Manual Testing  
- Automation Testing  
- API Testing  
- SQL for Testers  
- Non-Functional Testing  
- Agile & SDLC Practices  

The guide is designed to help QA testers learn and demonstrate **end-to-end testing capabilities**, from creating test plans to implementing automation scripts and API testing. It also provides practical samples and reusable templates that you can showcase in your portfolio.

# 🧠 Introduction

The **QA Testing Guide** serves as:

- 📚 A learning hub  
- 💼 A portfolio showcase  
- 🛠 A practical hands-on repository  

Whether you're just starting out or already experienced, this repository will guide you from basics to advanced testing techniques.

### This guide includes:

- **Theory**: SDLC, types of testing, test levels, strategies  
- **Hands-on Examples**: Automation scripts, API testing, SQL queries
